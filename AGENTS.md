# Research Compute Lab
Build this as a learning project with measurable infrastructure evidence.
Read README.md and CODEX_START.md before making changes.
Explain each milestone and the tradeoffs the user should be able to defend in an interview.
Keep local experiments separate from cloud deployments. Do not provision paid cloud resources without a user-approved budget and explicit deployment authorization.
Record real commands, environment details, results, and failures. Never invent benchmarks, successful deployments, or resume claims.
Use small, reviewable milestones. Test reproducibility, failure recovery, and configuration idempotence when relevant.
Run disruptive experiments only in this project's isolated lab, never against other projects or shared clusters.
Do not publish to GitHub or contact people unless the user requests it.
Milestone 0 is a single-machine CPU workload, not an HPC cluster. Keep that distinction in documentation.
